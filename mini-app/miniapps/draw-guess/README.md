# 画猜俱乐部

支持 2–8 人的联网你画我猜。玩家用六位房间号或大厅列表加入，轮流选词作画，其他人实时猜词。支持画笔、六色调色盘、橡皮、撤销、清空、断线重进和累计积分榜。

## 安装与开局

1. 使用支持 `ant.cloud.call` 的蚂蚁影视宿主，SDK 协议版本为 9。
2. 在「小程序 → + → 导入 zip 包」导入 [draw-guess-v1.zip](../../market/zip/draw-guess-v1.zip)。
3. 设置昵称、点击头像选择形象，然后创建画室，把房间号分享给朋友。
4. 其他玩家加入并准备后，房主开始游戏。每位玩家作画 1 或 2 次，每轮可选 60、75、90 秒。

绘画适合手机、平板触屏及桌面鼠标。电视遥控器支持界面焦点、按钮和输入框导航，可配合外接鼠标作画。

## 规则

- 画手从服务器分配的三个词中选择一个，12 秒未选则自动选择。答案仅发给画手。
- 第一位猜中获得 100 分基础分，后续每位递减 15 分，最低 50 分。按剩余时间额外奖励 0–30 分。
- 每位玩家猜中后，画手获得 25 分。每人每轮只计一次分。
- 本轮所有在线猜词玩家答对或时间耗尽后，展示答案，6 秒后自动换人。
- 中途加入的玩家可观战，下一局参与作画和计分。离线画手会被跳过，房主离线后由在线玩家接任。
- 全网榜按累计积分排序，显示猜中次数和完成局数。积分归属当前宿主的设备身份。

词库、答案、动作权限、时间和积分由宿主提供的画猜联网能力管理。画面由宿主房间的实时事件同步，重连时恢复服务器保存的画板。普通客户端的通用成绩提交接口无法修改本游戏的累计积分。

## 小程序开发

使用提供画猜联网能力的 SDK 9 宿主，直接安装即可开局，无需另行部署服务。
小程序通过 `ant.cloud` 调用宿主能力，不配置数据库或服务端密钥。
当前 appId 为 `com.leospring.drawguess`，通过 `ant.cloud.call('game', { action, options })`
获取游戏状态、提交动作和查询积分榜。调用能力与 appId 关联，修改前需确认宿主支持。

公开仓库提供小程序界面、交互代码及安装包。宿主内部实现由宿主项目管理。
完整云接口说明见 [联网开发参考](../../skills/miniapp-dev/references/cloud.md)。

在本仓库的 `mini-app` 目录校验和打包。

```sh
python3 -B skills/miniapp-dev/scripts/check_miniapp.py miniapps/draw-guess
python3 -B skills/miniapp-dev/scripts/pack_miniapp.py miniapps/draw-guess -o market/zip/draw-guess-v1.zip
```

包内资源全部使用相对路径，联网请求由宿主承担。纯浏览器可预览界面和自由练习，
完整联机需通过宿主运行，或自行接入开发用 cloud 适配器。
发布前应在两台宿主设备安装同一版本，验证画布同步、猜词计分、重进恢复和积分榜。
